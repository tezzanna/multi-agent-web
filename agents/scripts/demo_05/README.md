# Прогноз погоды в Москве

## Описание
Веб-приложение, которое показывает прогноз погоды в Москве на ближайшие 3 дня. Данные получаются с сервиса OpenWeatherMap.

## Запуск
Для запуска проекта не требуется установка дополнительных зависимостей или сборка.

1. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge).

## Функционал
- **Автоматическое получение данных:** При загрузке страницы приложение запрашивает актуальный прогноз погоды.
- **Отображение на 3 дня:** Показывает погоду на текущий день и два следующих дня.
- **Детали прогноза:** Для каждого дня отображается:
  - День недели и дата
  - Температура (округленная до целого)
  - Описание погодных условий
  - Иконка погоды
- **Адаптивный дизайн:** Корректное отображение на ПК, планшетах и мобильных устройствах.

## Технологии
- HTML5
- CSS3 (Flexbox, Grid, адаптивные медиа-запросы)
- JavaScript (ES6+, Fetch API, асинхронные функции)
- OpenWeatherMap API
